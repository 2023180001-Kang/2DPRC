# 2DPRC

Python과 pico2d로 만드는 기본 이동 프로토타입입니다. 요구 사항은 `PRD.md`를 참조합니다.

## 개발 환경

- Windows, Python 3.13.15
- pico2d 1.5.1, PySDL2 0.9.17, PySDL2-DLL 2.32.10
- 이미지 생성 및 검증 도구: Pillow 12.3.0

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

게임 실행 명령과 검증 결과는 구현 단계에서 추가합니다.
